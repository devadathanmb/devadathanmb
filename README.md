## Hi, I'm Devadathan (or _Dev_, because that's easier).

I live in Kerala, India. I spend my days building software at [Sage](https://github.com/sage), mostly on backend systems, and my evenings wondering how everything else works.

That curiosity has a habit of becoming a tool I wish already existed, or a five-hour detour for a 0.0001% improvement.

Libre and open-source software shape how I think about technology. A lot of what I know began with taking software apart to see how it worked. I use it and contribute when I can.

Sometimes I write things down before they fade: things I've learned, things I've built, and ideas worth returning to. They live at [devadathanmb.in](https://devadathanmb.in).
