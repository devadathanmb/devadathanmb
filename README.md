## Hi, I'm Devadathan (or _Dev_, because that's easier).

I live in Kerala, India. I spend my days building software at [Sage](https://github.com/sage), mostly on backend systems, and my evenings wondering how everything else works.

I care a lot about the software I use, and I like being able to change how it works. Sometimes that means five hours of configuring for a 0.0001% improvement. Other times it means writing my own tools because I couldn't get something to behave.

Libre and open-source software shaped the software engineer I wanted to become. Being able to read the code, change it, and learn from it mattered to me. It still does. I use it and contribute when I can.

Sometimes I write things down before they fade: things I've learned, things I've built, and ideas worth returning to. They live at [devadathanmb.in](https://devadathanmb.in).
